# chongming

`chongming` 是一个低成本多摄像机系统的研究项目，目标是在白天可见光条件下，对小型空中目标进行二维检测、三维定位和时序跟踪。本仓库当前处于编码前的架构与预研究阶段，尚未承诺特定端侧硬件、性能阈值或完整外场闭环。

## 系统概要

- 主相机面向天空，端侧输出二维候选、轨迹和世界射线事件。
- 辅助相机观察地面固定参照，用于端侧运行时校准；识别失败时冻结最后可信状态并明确标记过期。
- 中心端只在本地 PC 运行，接收世界射线并完成跨站关联、三维定位和三维临时 ID 跟踪。
- 虚拟环境的逻辑层与轻量渲染层分立，提供可重复的场景、视频占位输入、真值和可视化。

日常主规范见 [`instruction.md`](instruction.md)。架构与执行摘要分别见 [`架构设计.md`](架构设计.md) 和 [`计划.md`](计划.md)；背景材料集中在 [`背景资料/`](背景资料/)。

## 实施共识

项目按三步推进：先用文档和 UML 完成预研究与模块边界；再用 mock 验证数据结构、数据流和模块协同；最后按计划实现真实代码。三个月时间表仅用于顺利情况下的参考，不把未验证的时间安排当作承诺。
