# chongming

`chongming` 研究白天可见光条件下的多摄像站小型空中目标检测、三维定位与时序跟踪。主相机观测目标，辅助相机观测固定参照，设备端生成世界射线，本地 PC 执行中心融合。项目不提供目标类别识别，也不承诺探测距离、精度、硬件成本或外场闭环能力。

## 系统架构与数据流

本项目是**测试框架+业务代码**。框架提供虚拟环境、可视化工具和真值数据。

### 边缘侧算法（待测系统）

**输入**（来自 Godot）：

- 2 路视频流（主相机 + 辅助相机）
- 相机位置 `(x, y, z)`（世界坐标）
- 相机理想朝向 `(α₀, β₀)`（方位角、俯仰角）

**输出**（"射线包"）：

- 相机真实朝向 `(α, β)`（通过辅助相机校准）
- 飞行目标相对位置 `(Δα, Δβ)`（FOV 内偏移量）
- 射线描述：`[(x, y, z), (α+Δα, β+Δβ), (time, id)]`

每条射线是**世界坐标系中的一条从相机出发的方向**。射线包可被 Godot 截获并可视化，也可发送给中心端。

### 中心端算法（待测系统）

**输入**（"射线包"）：

- 来自多个边缘侧算法的射线包（真实或 Godot 伪装发包器）

**输出**（三维目标）：

- 三维空间中求交点：`[(x, y, z), (t, tgt_id), misc...]`
- 这是最终成果，可被 Godot 截获并可视化查看

### Godot 与 Python 的分工

用户只与 Godot 窗口交互（目标状态，实施中，见[设计说明](docs/design.md#交互边界)）；Python 在后台运行场景逻辑。

- **Godot**：渲染视频流；提供场景预览、编辑、播放控制及录制与运行入口；在 3D 场景中显示射线、交点和真值对比；集中显示运行信息与错误。
- **Python**：编译场景，计算运动与实验时钟；生成真值和伪装射线包，用于短接模块独立测试；执行录制与有限运行。

本框架只确定数据规范并验证数据可用。业务算法输出（射线、目标位置、体素得分）的具体可视化与打分，由业务算法开发者在 Godot 中实现。

**运行模式**：Godot 是用户的唯一终端，实现全部模式所需功能的并集；模式之间不是独立副本。记边缘侧算法为 A，中心端算法为 B：

| 模式            | 数据流                                                             |
| --------------- | ------------------------------------------------------------------ |
| 1. 空跑         | 预览并编辑场景，不接入算法                                         |
| 2. A 独立测试   | 场景视频 → A → 射线；Godot 显示并打分                              |
| 3. B 独立测试   | 射线包 → B → 目标位置或体素得分；Godot 显示并打分                  |
| 4. A+B 集成测试 | 场景视频 → A → B → 目标位置；Godot 显示并打分，可截获 A 输出的射线 |

模式 1 已可用。模式 2 至 4 在 Godot 中的显示与打分尚未实现。切换规则与边界见[设计说明：运行模式](docs/design.md#运行模式)。

## 当前实现

- 可重复的虚拟场景、独立主辅相机采样、Godot 4.7.2 渲染、预览编辑、有限运行与真值输出。
- 本地 OSM 地景和高度网格资产、JSON 内容摘要校验、卡片植被及简化摄影环境。
- OpenCV 辅助棋盘识别、姿态估计、校准历史与冻结/恢复状态机；预览及联合评估工具可运行该路径。
- 中心端分步开发工具，以及显式选择的参考融合与跟踪算法：事件准入、曝光窗口、多目标跨站关联、加权三维定位和恒速跟踪，支持已有轨迹的异步观测对齐。

默认 `InputInspector` 仍只检查输入。参考算法通过 `--algorithm chongming.reference:create_algorithm` 启用，使用普通虚拟射线，不读取目标真值；运行方法见[用户指南](docs/user-guide.md#参考融合与跟踪)。主相机检测、完整设备端射线链路、直接几何候选及通用系统编排尚未完成，详见[设计说明](docs/design.md#实现范围)。

## 源码快速开始

需要 Nix，并启用 `nix-command` 和 `flakes`。在源码根目录执行：

```sh
nix develop
uv sync --frozen
uv run --frozen chongming-center --scenario scenarios/center_clean.json --check
uv run --frozen chongming-preview --scenario scenarios/review.json
```

首次准备环境需要联网。预览需要图形会话和 OpenGL 3.3 驱动，默认地址为 <http://127.0.0.1:8765/>。`--no-video` 仍启动 Godot；无桌面 Linux 的运行方法见[开发指南](docs/development.md#图形环境)。

从用户发行归档安装普通 wheel，见[用户指南](docs/user-guide.md#安装)。
