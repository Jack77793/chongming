编辑会话独占锁：页面只修改草稿，Python 编译校验后由「提交 JSON」原子写回 authoring 文件；外部文件已改变时拒绝提交。

视频是 Godot 3D 渲染器输出的 sRGB RGB8 帧；真值标签只在预览中叠加。绿色线段表示可捕获的目标中心，红色线段表示被遮挡，黄色虚线表示普通虚拟射线，绿色箭头表示速度。主 1080p / 对角 FOV 60°，辅 VGA / 水平 FOV 2.6°。有限场景结束后自动循环；暂停后可单步检查。页面刷新与多个预览窗口不会改变实验采样。
